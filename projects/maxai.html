MaxAI

A conversational assistant inside the roofing.io CRM that turns a plain request into the right backend action.

role
Co-developer
company
Granular.ai
stack
Claude API, TypeScript, tRPC, React
link
roofing.io/agent ↗

problem

Contractors move between jobs, contacts, invoices, reports, and estimates. Each lives in a different screen or vendor tool, so a simple question like “collect the final check on this job” takes many clicks.

approach

  • Claude routes each request to one of 30 registered tools (jobs, contacts, KPI analytics, report ordering, estimate comparison).
  • Tools run through internal tRPC callers, the same typed backend the product already uses, so the assistant gets no separate code path or permissions model.
  • Replies come back as structured output that the UI renders as cards, not a wall of text.

result

Shipped as the assistant in the new CRM. The 30-tool registry is the concrete deliverable; I have not measured tool-selection accuracy yet, so I do not quote a number.
