Multi-lender quoting

A desktop quoting app where tenant isolation lives in the database, not just in application code.

type
Interview take-home project
stack
Electron, Cloud Run, Cloud SQL (PostgreSQL)
auth
IAM-based OAuth (PKCE)
code
GitHub ↗

problem

Several lenders use one quoting product. A bug in application code must not be able to show one lender’s data to another.

approach

  • PostgreSQL row-level security policies enforce tenant isolation at the database level.
  • The API runs on Cloud Run with Cloud SQL; authentication is IAM-based OAuth with PKCE.
  • Secret Manager holds credentials, so no cloud secrets ship inside the desktop client.

result

A working desktop app and API with isolation and secrets handled by design. This was a time-boxed take-home, so it has no production traffic or metrics to report.
